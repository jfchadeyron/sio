1. Le vocabulaire d'une balise

HTML
<a href="galerie.html">Ma galerie</a>
<a href="galerie.html">la balise ouvrante
ale nom de la balise
hrefun attribut : une option de la balise
"galerie.html"la valeur de l'attribut, entre guillemets
Ma galeriele contenu : ce qui s'affiche
</a>la balise fermante, avec une barre /

Un attribut s'écrit toujours dans la balise ouvrante : nom="valeur". Deux attributs sont séparés par un espace.

Une balise orpheline n'a ni balise fermante ni contenu : <meta>, <img>.

2. Le squelette d'une page

HTML
<!DOCTYPE html>              ← 1re ligne
<html lang="fr">             ← la langue
  <head>                     ← invisible
    <meta charset="utf-8">   ← les accents
    <title>Accueil</title>   ← l'onglet
  </head>
  <body>                     ← visible
    <h1>Bienvenue</h1>
    <p>Ma première page.</p>
  </body>
</html>

html est la racine : elle contient toute la page. head donne des informations sur la page ; body contient tout ce qui s'affiche à l'écran.

3. Le texte

<h1> à <h6>les titres, du plus important (h1) au moins important (h6)
<p>un paragraphe
<strong>un mot important (affiché en gras)
HTML
<h2>Mes compétences</h2>
<p>Je suis <strong>motivé</strong>.</p>
  • Un seul h1 par page : c'est le titre de la page.
  • On choisit un titre pour sa place dans le plan de la page, jamais pour sa taille.

4. La liste numérotée

HTML
<ol>
  <li>Ouvrir VS Code</li>
  <li>Créer le fichier index.html</li>
  <li>Enregistrer avec Ctrl+S</li>
</ol>

ol (ordered list) : la liste, numérotée toute seule. li (list item) : un élément.

  • Un li par élément ; jamais de texte directement dans le ol.
  • On choisit ol quand l'ordre a un sens : des étapes, un classement.

5. Ranger son site

Arborescence
portfolio/
├── index.html   la page d'accueil
├── galerie.html
└── images/
    └── photo-profil.jpg
  • La page d'accueil s'appelle toujours index.html.
  • Noms de fichiers et de dossiers : en minuscules, sans accent ni espace, mots séparés par des tirets. Ma Photo été.JPG devient ma-photo-ete.jpg.
  • Un nom qui décrit le contenu : photo-profil.jpg, pas IMG_2031.jpg.

6. Les chemins relatifs

Un chemin relatif part du fichier dans lequel on écrit le lien ou l'image.

Le fichier visé est...J'écris
dans le même dossiergalerie.html
dans un sous-dossierimages/photo-profil.jpg

images/ : j'entre dans le dossier images, puis je prends le fichier.

Jamais de chemin qui part du disque (C:\Users\...) : il ne fonctionne que sur ton ordinateur.

7. L'image

HTML
<img src="images/photo-profil.jpg" width="200">
srcsource : le chemin du fichier image (obligatoire)
widthla largeur, en pixels (facultatif)

img est une balise orpheline : elle n'a pas de balise fermante.

Une image cliquable : l'image est le contenu du lien.

HTML
<a href="galerie.html">
  <img src="images/vignette.jpg" width="150">
</a>

8. Le lien

HTML
<a href="cv.html">Mon CV</a>
<a>la balise du lien (anchor)
hrefla destination du lien (obligatoire)
Mon CVle texte cliquable

Vers une de mes pages, href contient un chemin relatif (bloc 6). Vers un autre site, l'adresse est complète et commence par https:// :

HTML
<a href="https://www.google.fr">Google</a>
  • target="_blank" ouvre le lien dans un nouvel onglet : seulement pour les liens vers un autre site.
  • Le texte du lien dit où l'on va : « mon CV détaillé », jamais « clique ici ».

9. Le tableau

HTML
<table width="100%">
  <tr>
    <th width="30%">Salle</th>
    <th>Postes</th>
  </tr>
  <tr>
    <td>B12</td>
    <td>16</td>
  </tr>
</table>
<table>le tableau entier
<tr>table row : une ligne
<th>table header : une cellule de titre (en gras et centrée)
<td>table data : une cellule
  • Le tableau se construit ligne par ligne : chaque tr contient ses th ou ses td.
  • Chaque ligne a le même nombre de cellules.
  • La ligne des titres s'écrit avec des th.

La largeur se règle avec l'attribut width :

<table width="100%">le tableau prend toute la largeur de la page
<table width="600">le tableau mesure 600 pixels
<th width="30%">la colonne occupe 30 % du tableau
<td width="150">la colonne mesure 150 pixels
  • En pixels, on écrit le nombre seul (600) ; en pourcentage, avec %.
  • Pour régler une colonne, il suffit de donner la largeur à sa première cellule.

10. La liste à puces et le menu

HTML
<ul>
  <li>Une équipe locale</li>
  <li>Une réponse rapide</li>
</ul>

ul (unordered list) : une liste à puces, quand l'ordre n'a pas de sens. Les éléments s'écrivent avec les mêmes li que dans ol.

Un menu est une liste de liens, rangée dans la balise nav (navigation) :

HTML
<nav>
  <ul class="menu">
    <li><a class="lien-menu" href="index.html">Accueil</a></li>
    <li><a class="lien-menu" href="services.html">Nos services</a></li>
  </ul>
</nav>
  • Le menu se place au tout début du body, avant le titre h1.
  • Il est identique sur toutes les pages du site.
