Mémo Git et GitHub

Les commandes de base pour sauvegarder ton portfolio et le publier en ligne

1. Une seule fois par ordinateur

git --versionVérifier que Git est installé.
git config --global user.name "Prénom Nom"Mon nom, qui signe mes commits.
git config --global user.email "adresse"Mon e-mail, le même que sur GitHub.
git config --global --listVérifier mes réglages (nom, e-mail).

2. Une seule fois par projet

git clone adresse-du-depotTélécharger le dépôt. Crée le dossier, déjà relié à GitHub.

L'adresse se copie sur GitHub : bouton vert Code, onglet HTTPS. Ensuite, dans VS Code : Fichier, Ouvrir le dossier, puis Terminal, Nouveau terminal.

3. À chaque séance

git pullEn arrivant : récupérer depuis GitHub.
git statusOù j'en suis ? Ne casse rien.
git add .Préparer tout ce qui a changé.
git commit -m "message"Enregistrer une version, sur mon PC.
git pushEn partant : envoyer sur GitHub.

4. Consulter et se repérer

git log --onelineL'historique, une ligne par commit (q pour sortir).
pwdDans quel dossier suis-je ?
lsQue contient ce dossier ?
cd portfolioEntrer dans le dossier portfolio.
cd ..Remonter d'un niveau.

5. À retenir

  • Un commit n'est pas un push. Sans git push, mon travail reste sur mon ordinateur.
  • Le message dit ce que j'ai fait, toujours entre guillemets : "Ajout de la section Contact". Jamais "modif" ni "test". L'historique est lu et évalué.
  • Jamais de mot de passe dans un dépôt. L'historique garde tout, même un fichier supprimé ensuite.

6. Publier avec GitHub Pages
