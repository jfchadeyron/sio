1. Écrire une règle

CSS
h1 {
  color: #1f4e79;
  font-size: 40px;
}
h1le sélecteur : ce que l'on vise
colorla propriété : ce que l'on change
#1f4e79la valeur : ce que l'on veut
{ }ouvrent et ferment la règle
: et ;deux-points après la propriété, point-virgule à la fin de chaque ligne
/* ... */un commentaire CSS (jamais <!-- -->)

2. Relier le CSS à une page

Dans le <head> de chaque page :

HTML
<link rel="stylesheet" href="css/style.css">

Un seul fichier css/style.css pour tout le site. Noms de dossiers et de fichiers en minuscules.

3. Les sélecteurs

J'écrisJe vise
bodytoute la page (le décor de base)
h1, p, a, li, td...tous les éléments de cette balise
h1, h2les h1 et les h2 (la virgule regroupe)
.introles éléments qui ont class="intro"
#contactl'élément unique qui a id="contact"

4. Classes et identifiant

HTML
<p class="intro">...</p>        .intro   { ... }
<td class="resolu">...</td>     .resolu  { ... }
<p id="contact">...</p>         #contact { ... }
  • Le point et le dièse s'écrivent seulement dans le CSS.
  • Une classe se réutilise sur autant d'éléments que l'on veut ; un identifiant n'apparaît qu'une fois par page.
  • Deux classes sur un élément : class="resolu a-rappeler" (séparées par un espace).
  • Noms en minuscules, sans accent ni espace, avec des tirets. Le nom dit le rôle, pas la couleur.

5. Quelle règle gagne ?

  1. L'identifiant #contact gagne sur la classe .intro.
  2. La classe gagne sur la balise p.
  3. À précision égale, la dernière règle écrite gagne.

Les propriétés qui ne se contredisent pas s'additionnent.

Héritage : ce qui est dans body passe à tout ce qu'il contient, sauf si l'élément a sa propre règle.

Pas d'attribut style dans les balises : il gagne sur tout et rend le CSS incompréhensible.

6. Les couleurs

colorles lettres (l'encre)
background-colorle fond (le papier)

Un code #rrvvbb : rouge, vert, bleu, de 00 à ff. Dans VS Code, le petit carré coloré ouvre la palette.

#000000 noir#ffffff blanc
#333333 gris foncé#f4f6f8 gris très clair
#1f4e79 bleu marine#c62828 rouge brique

Règle d'or : texte foncé sur fond clair, ou l'inverse. Jamais clair sur clair.

7. Le texte

PropriétéRôleExemple
font-familyla policeVerdana, sans-serif
font-sizela taille17px (collé)
font-weightle grasbold, normal
font-stylel'italiqueitalic, normal
text-alignl'alignementleft, center, right

Police : toujours une famille de secours à la fin (serif, sans-serif, monospace), et des guillemets si le nom contient un espace : "Courier New", monospace.

8. La boîte

Chaque élément est une boîte : contenu, puis padding, puis border, puis margin.

PropriétéRôleExemple
borderla bordure : épaisseur, style, couleur2px solid #1f4e79
border-bottomun seul côté (-top, -left, -right)3px solid #e67e22
paddingl'espace intérieur (le fond s'étend dessous)15px ou 10px 20px
marginl'espace extérieur (transparent)20px ou 0 auto
widthla largeur du contenu300px, 100%
max-widthla largeur maximale800px

Styles de bordure : solid, dashed, dotted, double. Sans style, pas de bordure.

Deux valeurs : padding: 10px 20px; = 10 px en haut et en bas, 20 px à gauche et à droite.

Centrer la page : body { max-width: 800px; margin: 0 auto; }

Largeur réelle = width + 2 × padding + 2 × border.

Tableau à traits simples :

CSS
table { border-collapse: collapse; }
td    { border: 1px solid #999999;
        padding: 8px; }

9. Le menu horizontal

CSS
.menu {
  display: flex;
  list-style: none;
  gap: 30px;
  padding: 0;
  margin: 0;
}
.lien-menu {
  color: #ffffff;
  text-decoration: none;
}
display: flex;range les éléments de la liste côte à côte
list-style: none;supprime les puces
gap: 30px;l'espace entre les éléments
padding: 0; et margin: 0;suppriment les espaces que le navigateur ajoute autour d'une liste
text-decoration: none;supprime le soulignement d'un lien

Ça ne marche pas ?

Rien ne change<link> absent ou chemin faux (F12, Console : 404).
Une ligne ignorée; ou : oublié : regarde la ligne au-dessus.
Classe sans effetpoint oublié dans le CSS, point en trop dans le HTML, nom différent (majuscule, accent).
Tout le bas est casséune } oubliée.
Bordure invisiblele style manque : solid.
Code juste, rien ne bougeCtrl+S, puis Ctrl+F5.
OK en local, pas en ligneune majuscule dans un nom de fichier.

« Le CSS ne crie jamais, il ignore. » L'inspecteur (clic droit, Inspecter) montre les règles appliquées et barre celles qui perdent.

Pas encore vu : ne pas utiliser

span, div · border-radius · sélecteurs combinés (td.urgente, .tableau td, nav a) · a:hover · Google Fonts · les autres réglages de Flexbox (justify-content, align-items) · :root et les --variables · !important · box-sizing
