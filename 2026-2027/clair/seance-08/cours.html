Le site vitrine et le menu horizontal

Concevoir un site de plusieurs pages et relier ces pages par un menu

Objectifs de la séance

À la fin de la séance, tu sais :

  • expliquer ce qu'est un site vitrine et le concevoir avant de coder : quelles pages, quels fichiers, quel contenu ;
  • écrire une liste à puces avec ul ;
  • construire un menu de navigation et placer ses liens côte à côte ;
  • relier plusieurs pages entre elles avec le même menu.

Déroulement : on conçoit ensemble le site vitrine de TechSolutions, puis on construit le menu pas à pas. Ensuite, tu fais le TP : le squelette complet du site, dans ton dépôt portfolio.

1. Un site vitrine, c'est quoi ? 5 min

Un site vitrine présente une entreprise au public, comme la vitrine d'un magasin : qui elle est, ce qu'elle propose, comment la contacter. On ne s'y connecte pas, on ne commande rien : on lit.

Notre client, TechSolutions, est une entreprise de services informatiques (entreprise fictive) installée à Brive-la-Gaillarde. Elle dépanne, entretient et sauvegarde l'informatique des petites entreprises de la région. Elle n'a pas encore de site internet : c'est toi qui vas le construire, séance après séance.

2. Concevoir avant de coder 10 min

Un développeur ne commence jamais par taper du code. Il commence par répondre à trois questions :

  1. Quelles pages ? Ce que le visiteur doit pouvoir trouver.
  2. Comment passe-t-on d'une page à l'autre ? Le menu.
  3. Que contient chaque page ? Les titres et les textes.

2.1 L'arborescence

L'arborescence est le plan du site : la liste des pages et leurs liens. Pour TechSolutions, quatre pages suffisent :

Chaque page est un fichier HTML. Tous les fichiers sont rangés dans le même dossier, avec la feuille de style dans css/ et les images dans images/ :

techsolutions/
├── index.html         la page d'accueil (toujours index.html)
├── services.html
├── entreprise.html
├── contact.html
├── css/
│   └── style.css      une seule feuille de style pour tout le site
└── images/            vide pour l'instant

2.2 Le contenu de chaque page

Toutes les pages ont la même organisation, de haut en bas : le menu, le titre de la page, le contenu, puis une ligne de bas de page avec les coordonnées. Seul le contenu change d'une page à l'autre.

Le squelette d'un site

Le squelette d'un site, ce sont toutes ses pages, déjà reliées entre elles, avec leurs titres et un contenu provisoire. Le site est « vide », mais on peut déjà le parcourir. On l'habillera ensuite avec le CSS et les vrais textes.

3. La liste à puces : ul 5 min

Tu connais la liste numérotée ol. Quand l'ordre n'a pas d'importance, on utilise la liste à puces ul (unordered list, liste non ordonnée). Les éléments s'écrivent avec les mêmes li :

<ul>
  <li>Une équipe locale</li>
  <li>Une réponse rapide</li>
  <li>Des tarifs clairs</li>
</ul>
  • Une équipe locale
  • Une réponse rapide
  • Des tarifs clairs

Le navigateur affiche un point devant chaque élément. Un menu de site n'est rien d'autre qu'une liste de liens dont l'ordre n'a pas de sens particulier : c'est donc une ul.

4. Le menu, pas à pas 25 min

4.1 Le HTML du menu

Le menu se place au tout début du body, avant le titre :

techsolutions/index.html<body>
  <nav>
    <ul class="menu">
      <li><a class="lien-menu" href="index.html">Accueil</a></li>
      <li><a class="lien-menu" href="services.html">Nos services</a></li>
      <li><a class="lien-menu" href="entreprise.html">L'entreprise</a></li>
      <li><a class="lien-menu" href="contact.html">Contact</a></li>
    </ul>
  </nav>

  <h1>TechSolutions</h1>
ÉlémentRôle
<nav>navigation : la boîte qui contient le menu principal du site. Elle n'affiche rien de spécial, mais elle dit au navigateur (et aux logiciels qui lisent les pages à voix haute pour les personnes aveugles) : « ceci est le menu ».
<ul class="menu">la liste des liens. La classe menu permettra de mettre en forme cette liste sans toucher aux autres listes de la page.
<li>un élément du menu.
<a class="lien-menu" href="...">le lien vers une page. La classe lien-menu le distingue des autres liens de la page.

Les adresses des liens sont simplement les noms des fichiers : toutes les pages sont dans le même dossier, le navigateur les trouve directement.

Résultat sans CSS

Quatre liens bleus soulignés, l'un sous l'autre, chacun précédé d'un point. C'est une liste à puces ordinaire.

  • Accueil
  • Nos services
  • L'entreprise
  • Contact

4.2 Mettre les liens côte à côte

Dans css/style.css, ajoute une partie pour le menu :

css/style.css/* ===== Le menu ===== */
.menu {
  display: flex;
  list-style: none;
  gap: 30px;
  padding: 0;
  margin: 0;
}
DéclarationCe qu'elle fait
display: flex;Par défaut, chaque li prend toute une ligne : les éléments s'empilent. display: flex demande à la liste de ranger ses éléments côte à côte, sur une même ligne.
list-style: none;Supprime les puces (les points devant chaque élément).
gap: 30px;Met 30 px d'espace entre les éléments : rien avant le premier, rien après le dernier.
padding: 0;Le navigateur ajoute d'office un espace intérieur à gauche de toute liste, pour y loger les puces. Les puces ont disparu mais cet espace reste : on le supprime, sinon le menu est décalé vers la droite.
margin: 0;Supprime les marges que le navigateur met au-dessus et au-dessous de la liste.
padding ou gap ? L'image des meubles

Imagine la liste comme une pièce et les liens comme des meubles. Le padding, c'est l'espace entre le mur de la pièce et les meubles. Le gap, c'est l'écart entre les meubles eux-mêmes.

4.3 La barre du menu et ses liens

Complète la partie « Le menu » :

css/style.cssnav {
  background-color: #123c63;
  padding: 12px 20px;
  margin-top: 20px;
}

.lien-menu {
  color: #ffffff;
  font-weight: bold;
  text-decoration: none;
}

Une seule propriété est nouvelle : text-decoration: none; supprime le soulignement des liens. Dans un menu, on sait déjà que ce sont des liens : le soulignement est inutile.

Résultat avec CSS
  • Accueil
  • Nos services
  • L'entreprise
  • Contact
Point d'étape

Sur la page d'accueil, la liste « Pourquoi nous choisir ? » est aussi une ul. Pourquoi garde-t-elle ses puces et reste-t-elle verticale, alors que le menu est devenu horizontal ?

5. Le même menu sur toutes les pages 5 min

Le menu doit apparaître sur chaque page, exactement à l'identique. En HTML, il n'y a qu'une façon de faire : copier le bloc <nav> et le coller au début du body de chaque page.

  • Pour aller vite : termine complètement index.html (squelette, menu, lien vers la feuille de style), puis fais Fichier, Enregistrer sous pour créer les trois autres pages. Il ne reste qu'à changer le titre de l'onglet, le h1 et le contenu.
  • Si tu ajoutes une page plus tard, il faudra ajouter son lien dans le menu de toutes les pages. C'est un peu fastidieux : plus tard dans l'année, on verra comment écrire le menu une seule fois.
  • La feuille de style, elle, est déjà commune : chaque page la relie avec la même ligne <link rel="stylesheet" href="css/style.css">.
Un lien qui mène à une erreur

Si un lien affiche « Fichier introuvable », compare lettre par lettre le href et le nom du fichier : Services.html n'est pas services.html. Sur ton ordinateur, ça peut fonctionner quand même ; en ligne, sur GitHub, jamais.

6. Enregistrer ton travail

Le site TechSolutions se range dans ton dépôt portfolio, dans un dossier techsolutions. À la fin de la séance :

git add .
git commit -m "TechSolutions : squelette du site vitrine et menu"
git push

Ton site sera alors visible à l'adresse https://ton-pseudo.github.io/techsolutions/.

À retenir
  • Avant de coder, on conçoit : l'arborescence (les pages et leurs liens), puis le contenu de chaque page. Une page = un fichier HTML ; la page d'accueil s'appelle index.html.
  • ul : liste à puces, quand l'ordre ne compte pas. Un menu est une ul de liens, dans un nav.
  • Le menu horizontal : display: flex (côte à côte), list-style: none (sans puces), gap (espace entre les liens), padding: 0 et margin: 0 (supprimer les espaces ajoutés par le navigateur).
  • text-decoration: none supprime le soulignement d'un lien.
  • Le même bloc nav est copié sur toutes les pages ; les classes menu et lien-menu évitent de modifier les autres listes et les autres liens.
